# ✈️ TripPilot

### Planeje sua próxima viagem com o poder da Inteligência Artificial.

O **TripPilot** é uma plataforma inteligente de planejamento de viagens que utiliza Inteligência Artificial para criar roteiros completos e personalizados em poucos segundos.

O usuário informa seu destino, local de partida, orçamento, datas e preferências, e a IA gera um roteiro completo contendo sugestões de voos, hospedagens, atrações, transporte e muito mais.

# 📖 Sobre o projeto

Planejar uma viagem normalmente exige pesquisar passagens, comparar hotéis, encontrar atrações, montar um roteiro e organizar todas essas informações.

O **TripPilot** nasceu para simplificar esse processo utilizando Inteligência Artificial.

Em poucos segundos o usuário recebe um roteiro totalmente personalizado baseado em:

- 📍 Local de partida
- 🌎 Destino
- 📅 Data da viagem
- 💰 Orçamento disponível
- ❤️ Preferências pessoais

Além disso, o projeto foi pensado para possuir uma arquitetura escalável, permitindo a integração com diferentes modelos de IA e APIs de turismo.

# ✨ Funcionalidades

- 🤖 Geração de roteiros com Inteligência Artificial

- 🗓️ Organização diária da viagem
- 💰 Planejamento baseado no orçamento
- 🧠 Escolha entre diferentes modelos de IA
- ❤️ Salvar roteiros favoritos
- 👤 Sistema de autenticação
- 📱 Interface moderna e responsiva
